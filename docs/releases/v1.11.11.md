# v1.11.11

此版本修复了节点调度、站点流量计量、TLS 证书与备份、页面设置保存、安装器升级与卸载，以及媒体清单路由中的问题。Controller、Agent 和 Go 测试统一移入 `cmd/meridian/`，原生安装入口仍为仓库根目录的 `install.sh`。

## 修复

- 站点入口现在使用 Agent 已确认生效的 HTTPS 端口；配置尚未 ACK 时显示等待状态，不再复制期望端口。
- 删除节点时，在同一事务内把该节点已计费的分钟流量合并到站点账本，保留周期用量、额度判断、趋势和告警；不重复增加累计流量。
- 修正节点月度周期跨越二月末时的重置边界。生产面板证书复用前会验证完整的系统信任链和请求域名。
- TLS 备份将数据库节点清单绑定到同一快照，并在节点证书内容固定后释放变更锁，避免并发删除造成证书缺失。
- TMDB、Telegram 与 TLS 页面为请求回调绑定页面代次，并保护请求期间继续输入的草稿；清理缓存只刷新统计。相同数量的站点上游请求头变化也会触发正确刷新。
- 安装器更新回滚和卸载前确认服务已经停止；健康探测使用应用当前监听协议与端口。数据目录校验继续避免误认和误清理非 Meridian 目录。
- 固定回源与通用反代的相对 `PlaybackInfo` 地址保留后端所需请求头；DASH XML 命名空间保持有效；路径前缀不会吞掉应用自身同名路径。
- HLS 同一清单内定义的变量会在 URI 验证和代理能力路由之前有限展开；不支持的跨清单 IMPORT 或无法安全解析的变量引用不会原样放行。

## 兼容性

保留固定回源及通用反代的认证、UA 和请求头透传，继续支持 Emby `/emby` 挂载、嵌套 canonical 路由、签名查询、重定向后端识别及 Range/206 播放。通用反代仍允许管理员配置的 HTTP(S)、内网和本机目标。此模式应仅暴露给可信用户。

## 数据库

从 v1.11.9 升级时，数据库从 schema 58 迁移到 60。新版在站点调度记录中保存节点已应用的端口。升级时回填已确认的端口，未确认的端口保持未知。回退到 v1.11.9 前，需恢复升级前的 schema 58 数据库备份。

## 验证

- `go test ./...`、关键代理/数据/备份 `-race` 回归、`go vet ./...`。
- Node 前端测试、安装器健康与生命周期隔离测试、Go/Docker/安装器脚本构建路径检查。
- 发布工作流还会运行 Windows/macOS vet、`govulncheck`、`gosec`、CodeQL 精确提交门禁，并构建 Linux/Windows/macOS Controller、Linux Agent 与 amd64/arm64 GHCR 镜像。
