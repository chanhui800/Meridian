# v1.11.14

修复站点管理页面在后台刷新或删除站点后意外跳回顶部的问题。

## 站点管理

- 列表刷新和站点删除后保留当前可见位置，删除视口上方的站点时也会尽量保持当前浏览行不动。
- 关闭删除确认弹窗时恢复键盘焦点，但不再让浏览器为了焦点滚动页面。
- 删除最后一个站点时，页面按剩余内容高度调整滚动范围。

## 数据库与回退

本版本不更改数据库结构。保留现有数据即可升级；回退时按原版本要求恢复程序，无需额外数据库迁移。

## 验证

- 前端全套 424 项测试通过。
- Edge 和 Firefox 的桌面与移动视口共完成 26 项滚动行为检查，覆盖连续刷新、弹窗跨越后台刷新、删除、搜索筛选，以及请求过程中继续滚动。
