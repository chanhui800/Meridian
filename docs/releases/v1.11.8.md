# Meridian v1.11.8

v1.11.8 修复控制台下拉选项文字被裁切和垂直偏移的问题，并统一各页面下拉控件的垂直排版。

## 控件显示

- 修复创建节点弹窗中 DNS 发布和计费方式选项的文字裁切。
- 统一节点调度、站点配置、全局设置、仪表盘和观看记录筛选器的下拉控件行高与纵向内边距。
- 保留桌面与移动端现有控件高度、主题颜色和原生选择交互。

## 升级

本版本不包含数据库结构变更。正式文件和 `SHA256SUMS` 发布后可在 [v1.11.8 Release](https://github.com/chanhui800/Meridian/releases/tag/v1.11.8) 获取，固定镜像为 `ghcr.io/chanhui800/meridian:v1.11.8`。
